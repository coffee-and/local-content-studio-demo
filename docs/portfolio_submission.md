# 프리모아 포트폴리오 등록 문구

## 제목

**Cognex 경험을 바탕으로 구현한 OpenCV 로컬 이미지 모자이크 및 AI 콘텐츠 생성 Windows 프로그램**

## 한 줄 소개

**PySide6, OpenCV, SQLite, OpenAI API를 활용해 이미지 로컬 처리부터 콘텐츠 생성·이력·스케줄·Drive 동기화 폴더 저장까지 구현한 Windows 데스크톱 데모입니다.**

## 상세 설명

Cognex 비전 시스템 관련 업무에서 경험한 로컬 이미지 처리 흐름을 바탕으로, 지원 프로젝트의 요구사항을 공개 가능한 개인 기술 검증 프로그램으로 재구성했습니다.

Windows 데스크톱 환경에서 이미지를 불러오고, OpenCV를 이용해 얼굴·번호판 또는 사용자가 지정한 영역을 모자이크 처리할 수 있습니다. 원본 파일은 직접 수정하지 않고 결과물을 별도 저장하며, 한글 경로와 처리 실패 등 실제 운영 시 발생할 수 있는 예외 상황도 고려했습니다.

또한 OpenAI API 기반 제목·본문 생성, TXT 프롬프트 관리, 지역·키워드 로테이션, 중복 콘텐츠 방지, SQLite 생성 이력, 반복 스케줄, Google Drive Desktop 동기화 폴더 저장 기능을 하나의 데스크톱 프로그램으로 통합했습니다. API 키 없이도 기능 흐름을 확인할 수 있도록 Mock 모드를 제공하며, API 키는 저장소나 DB에 보관하지 않습니다.

회사 및 고객사 보안을 위해 실제 Cognex 프로젝트의 소스코드, 설비 화면, 생산 이미지, 고객사 정보는 사용하지 않았습니다. 모든 코드는 새로 작성했으며, 샘플은 포트폴리오 시연을 위해 AI로 생성한 가상 사고 이미지입니다. 실제 인물, 차량 또는 사고 현장 데이터가 아닙니다.

## 담당 및 구현 범위

- PySide6 기반 Windows 데스크톱 UI
- OpenCV 수동 ROI 모자이크·블러
- Haar Cascade 기반 얼굴·번호판 보조 검출
- 폴더 일괄 이미지 처리
- OpenAI 제목·본문 생성 및 Mock 모드
- 프롬프트 TXT·지역·키워드 관리
- 콘텐츠 해시·문자열 유사도 기반 중복 방지
- SQLite 생성·이미지·오류·스케줄 이력
- Google Drive Desktop Sync 폴더 저장
- PyInstaller EXE 빌드와 단위 테스트

## 프로젝트 연관성

지원 프로젝트의 핵심인 Windows EXE, OpenAI 콘텐츠 생성, 프롬프트 로테이션, SQLite 이력, 스케줄러, Drive Sync 폴더 저장, OpenCV 로컬 모자이크 처리의 전체 흐름을 직접 시연할 수 있습니다.

## 유의사항

번호판 자동 검출은 범용 Haar Cascade를 이용한 데모 기능으로, 한국 번호판의 운영 정확도를 보장하지 않습니다. 실제 납품 범위에서는 요구 정확도와 데이터 조건에 따라 전용 모델 또는 수동 보정 방식을 협의해야 합니다.
