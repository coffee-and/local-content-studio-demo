# 3분 시연 순서

## 1. 대시보드 — 15초

- 프로그램이 Windows EXE 형태의 데스크톱 앱임을 설명
- OpenAI 콘텐츠, OpenCV 이미지, SQLite, 스케줄러가 한 프로그램에 통합되었다고 설명

멘트 예시:

> Cognex 환경에서 경험한 로컬 이미지 처리 흐름을 바탕으로, 공고 요구사항을 공개 가능한 개인 데모로 재구성했습니다. 웹 서비스가 아니라 Windows PC에서 실행되는 데스크톱 프로그램입니다.

## 2. 이미지 모자이크 — 60초

1. AI로 생성한 가상 사고 샘플 3장 중 하나 열기
2. 번호판 영역 두 곳을 마우스로 지정
3. 모자이크 강도 조절
4. 미리보기
5. 결과 저장
6. 이력 탭에서 원본 경로, 결과 경로, ROI 개수 확인

멘트 예시:

> 이 샘플은 실제 인물이나 사고 현장 데이터가 아닌 AI 생성 이미지입니다. 이미지 처리는 외부 서버로 보내지 않고 OpenCV로 로컬 처리하며, 자동 검출 결과가 없거나 정확하지 않을 때는 수동 ROI를 최종 안전장치로 사용할 수 있습니다.

## 3. 콘텐츠 생성 — 50초

1. 지역·키워드 자동 로테이션 선택
2. Mock 모드에서 생성
3. 제목·본문과 저장 경로 확인
4. 같은 조건으로 다시 생성해 중복 차단 기록 확인

멘트 예시:

> API 키가 없어도 전체 흐름을 검토할 수 있도록 Mock 모드를 넣었습니다. 실제 모드에서는 OpenAI Responses API를 호출하며 제목·본문 해시와 유사도를 이용해 중복을 검사합니다.

## 4. 프롬프트·스케줄 — 35초

1. TXT 프롬프트 수정
2. 지역·키워드 목록 확인
3. 1분 스케줄 추가
4. 즉시 실행 버튼으로 결과 생성

멘트 예시:

> 프롬프트와 지역·키워드는 코드 수정 없이 관리할 수 있고, 예약 정보는 SQLite에 저장됩니다.

## 5. Drive 저장과 마무리 — 20초

- 설정 탭에서 Google Drive Desktop 동기화 폴더를 지정할 수 있음을 보여줌
- 네이버 자동 포스팅과 웹 서비스는 의도적으로 제외했다고 설명

마무리 멘트:

> 이 데모는 실제 고객사 코드를 사용하지 않은 클린룸 구현입니다. 운영 단계에서는 검출 정확도 기준과 Windows 백그라운드 실행 방식 등을 협의해 확장할 수 있습니다.
